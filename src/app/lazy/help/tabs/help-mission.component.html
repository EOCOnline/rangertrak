At the start of a mission

On Mission, set the mission name and the operational period, and a default latitude and longitude near your operating area — new reports start from there, which saves typing on every single one.

Mission settings are not saved until you press Save. Unlike the Reports and Rangers grids, which save edits themselves, this page waits for you.

Most of the rest of the page has a sensible default and can be left alone. The settings below are the ones worth knowing about, because their effect shows up somewhere else.

Settings with consequences elsewhere

Setting What it changes
Coordinate systems shown on Entry Hides formats your team never uses from the entry screen. If a format has gone missing, this is why.
Field Report Statuses The status buttons on the entry screen, and the marker colours. A status already used by a report cannot be renamed.
Google Geocoding API key Optional. Address lookup uses OpenStreetMap by default, free and with no key. Your own Google key switches address lookup to Google, at your own cost. Neither works offline.
Debug Mode Adds diagnostic detail to the entry screen and the grids. For reporting a problem, not for normal use.

Advanced Options

Collapsed at the bottom of the page. Four things live there:

  • Request Persistent Storage — ask the browser not to discard your mission when it is short of space. Accept if offered.
  • Export Mission / Import Mission — the whole mission as one file, for backup or handover to another device.
  • Load Sample Mission — a ready-made demonstration mission, for training or showing someone the app.
  • Reset Settings — back to defaults, at the start of a new incident.
Load Sample Mission, Import Mission and Reset Settings all replace what is on this device. Export first if you need to keep it.
