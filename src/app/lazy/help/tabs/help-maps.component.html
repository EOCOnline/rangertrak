Saving map coverage before you lose the network

Map areas you have never viewed or saved are blank when the network goes. Save the area while you still have a signal — not when you need it. See the Guide button in the header for how, on either engine.

Two map engines

Engine Use it when
Leaflet (shown by default) Best detail, anywhere in the world. Needs Internet for areas you have not saved.
MapLibre + PMTiles (the switch below the map) Map data ships inside the app, so it works with no connection at all — but detailed coverage is currently limited to the pilot region.

Route trails join one ranger's reports oldest to newest, on both engines, so you can see which way a team has been moving — the label at the newest end is a snapshot from when the map was drawn, not a running clock.
