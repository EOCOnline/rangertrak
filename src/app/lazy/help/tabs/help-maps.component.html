Saving map coverage before you lose the network

This is the one thing on the map page worth doing in advance. Zoom to your operating area and press Save this area for offline use, below the map. Those tiles are then held on this device and the map keeps drawing with no connection.

Map areas you have never viewed or saved are blank when the network goes. Save the area while you still have a signal — not when you need it.

Two map engines

Engine Use it when
Leaflet (shown by default) Best detail, anywhere in the world. Needs Internet for areas you have not saved.
MapLibre + PMTiles (the switch below the map) Map data ships inside the app, so it works with no connection at all — but detailed coverage is currently limited to the pilot region.

On the Leaflet map, the control in the top-right corner switches the base map between street and topographic.

Reading the map

  • Each ranger has their own marker — a distinct shape and colour, derived from the call sign, so the same person looks the same on every map and in every session.
  • Lines join one ranger's reports in order, oldest faintest, so you can see which way a team has been moving. The label at the newest end shows how long ago that report came in — it is a snapshot from when the map was drawn, not a running clock.
  • Nearby reports group into a cluster. Click it to zoom in and separate them.

Showing only some reports

By default the map shows every report. Select rows on the Reports page, then use the switch under the map to show just those — useful for one team, one time window, or one status.

Clicking the map copies those coordinates to the clipboard.
