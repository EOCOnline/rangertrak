Get set up

  1. Set up your mission. Open Mission and set the mission name, the operational period, and a default latitude/longitude near your operating area — new reports start from there, which saves typing on every single one.
    Mission settings are not saved until you press Save. Unlike the Radio Log and Rangers grids, which save edits themselves, this page waits for you.
  2. Load your roster. Open Rangers and import or add your team.
  3. Go to Field Entry. Click the RangerTrak name in the header to get there (it is also the home page). That is where you will spend the incident.

The coloured dot in the page header tracks those three steps. Hover it for what is still missing; click it to jump to Mission.

Do this before you need it. RangerTrak works with no Internet — but only once it has loaded at least once on this device. A device that has never opened RangerTrak and has no connection gets nothing. Install it, and open the map for your area, while you still have a signal.

Most of the rest of the Mission page has a sensible default and can be left alone. These are the ones worth knowing about, because their effect shows up somewhere else.

Setting What it changes
Coordinate systems shown on Entry Hides formats your team never uses from the entry screen. If a format has gone missing, this is why.
Field Report Statuses The status buttons on the entry screen, and the marker colours. A status already used by a report cannot be renamed.
Google Geocoding API key Optional. Address lookup uses OpenStreetMap by default, free and with no key. Your own Google key switches address lookup to Google, at your own cost. Neither works offline.
Debug Mode Adds diagnostic detail to the entry screen and the grids. For reporting a problem, not for normal use.
Works with no Internet Needs a connection
Entering and saving reports Looking up a street address
All coordinate formats, and Plus Codes Map areas you have not already viewed or saved
Roster, report table, export and import Sending feedback

Coordinates and Plus Codes are calculated on your device, so they keep working when nothing else does. Addresses have to be looked up. See Maps for saving map coverage ahead of time.

Collapsed at the bottom of the Mission page. Four things live there:

  • Request Persistent Storage — ask the browser not to discard your mission when it is short of space. Accept if offered.
  • Export Mission / Import Mission — the whole mission as one file, for backup or handover to another device.
  • Load Sample Mission — a ready-made demonstration mission, for training or showing someone the app.
  • Reset mission to defaults — back to defaults, at the start of a new incident.
Load Sample Mission, Import Mission and Reset mission to defaults all replace what is on this device. Export first if you need to keep it.
