Diagnostic log

RangerTrak keeps a running record of what it did this session - useful mainly when something goes wrong and you want to report it, or figure out why.

Open the Log page

There is no menu entry for it on purpose - it is a diagnostic tool, not something you need during normal use. This tab exists so it is still easy to find when you do need it.

Reporting a problem

On the Log page, press Save Log File and attach it to your bug report - it is far more useful than a description of what went wrong. See the Your data tab for what the log does and does not contain.
