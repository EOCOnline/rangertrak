RangerTrak™ is an open-source application for tracking & mapping SAR, CERT, ACS, other teams, rangers & individuals roaming around, who are only reliably connected via HAM radio or other non-data supporting means. They can radio in their locations - in a variety of formats, and be centrally tracked.

Once loaded, RangerTrak keeps working with no Internet: entering and saving reports, the roster, the report table, coordinate conversion, and mission export/import are all local to your device.

Items requiring online access:

  • Geocoding an address (and the reverse: coordinates to a street address)
  • The Leaflet map, except for areas saved in advance for offline use
  • The offline (MapLibre) map needs to be opened once while connected, after which it works with no Internet

Coordinates always work offline, and so do Plus Codes — they are calculated on your device rather than looked up over the network. Addresses need a connection. See the Field Guide for how to prepare a device before a mission.

Supported coordinate formats: Decimal Degrees, Degrees/Decimal Minutes, Degrees Minutes Seconds, MGRS (the US military/FEMA grid standard), UTM, and Maidenhead grid locators (typed into the address field alongside Plus Codes and street addresses). All formats assume WGS84/modern GPS — a position read off an older paper topo quad may use the NAD27 datum instead, which can be 100–200m off in the western US.

An overview of using location codes (instead of lat/long) can be found at:
https://github.com/google/open-location-code/wiki/Evaluation-of-Location-Encoding-Systems

For more information and to report issues please visit https://github.com/EOCOnline/RangerTrak.

  • Progressive Web App (PWA): after the initial load, installable & runs w/o Internet
  • Angular 22 with TypeScript, Angular signals, zoneless change detection, and Material Design
  • Leaflet maps with marker clustering, overview map, and offline tile caching
  • MapLibre GL + PMTiles: a vector map with basemap data bundled into the app, for true offline use
  • Geocoding via OpenStreetMap's Nominatim — no API key required
  • Plus Codes and lat/long conversion (Decimal Degrees, DMS, DDM, MGRS, UTM, Maidenhead), all computed on-device
  • AG Grid tables with searching, sorting, filtering and export
  • Custom Angular components, such as the colour & time pickers and the location widget
  • Angular Signal Forms (the app's forms moved off Reactive Forms in the 0.15.x redesign)
  • No cookies, no accounts, no server: data is held in your browser's Local Storage
  • Cross platform: runs on any modern browser, using only standard HTML 5 & CSS 3

    • FUTURE:

  • What3Words address entry (previously present, currently shelved pending an SDK migration)
  • Downloadable offline map regions beyond the bundled pilot area
  • Tracking teams that have not reported in within an expected interval
  • Data passed to servers (when Internet connectivity allows) for remote display of data & maps

Grid Menu Keyboard interaction
The AG Grid tables' column and filter menus (Rangers, Field Reports) support:
Down Arrow - Focus the next menu item.
Up Arrow - Focus the previous menu item.
Left Arrow - Close the current menu if it is a sub-menu.
Right Arrow - Opens the current menu item's sub-menu.
Enter - Activate the focused menu item.
Escape - Close all open menus.
