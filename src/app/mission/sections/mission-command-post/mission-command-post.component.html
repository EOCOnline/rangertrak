Run npm run command-post (or the packaged equivalent) on a command-post laptop - a phone or tablet can publish reports TO this (below), but cannot run the server itself. There's nowhere on iOS/Android for it to listen for connections the way a laptop's OS lets it; this is a deliberate limit, not a gap this app works around. Then turn this on and point it at that laptop's address. Teams on the same WiFi/hotspot can then open /view on that address to see a read-only, auto-refreshing comms log - no roster, no photos, and nothing is written back. If the server isn't running, this silently does nothing; your own copy of the mission is never affected either way.

The server address starts with https://, not http:// - the server generates its own certificate, so the FIRST time you (and anyone viewing) visit that address, the browser will warn "Your connection is not private." That's expected for a private server, the same warning most home routers show. Click Advanced, then Proceed - needed once per device, not every time. Visit the address directly in this browser and accept that warning BEFORE turning the toggle on below - otherwise publishing fails silently, with no error shown here.
