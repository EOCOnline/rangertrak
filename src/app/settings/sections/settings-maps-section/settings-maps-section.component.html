Geocoding

Google Geocoding API Key (optional):
By default, address lookup uses Nominatim (OpenStreetMap) - no key required, but requires Internet. Supplying your own Google API key here switches address lookup to Google Geocoding instead. This key is stored only in your browser and is your own billing responsibility.
