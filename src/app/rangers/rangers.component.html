This roster holds personal data: legal names, home addresses, personal phone numbers and photos, alongside call signs that tie each row to a named, publicly-searchable FCC licence. Treat it as confidential participant information, not as operational data.

  • It is stored unencrypted in this browser's local storage. Anyone with access to this device and browser profile can read it.
  • Exports (CSV, Excel, and Mission Backup) are unencrypted plain-text files. Once exported, this app can no longer protect them.
  • Share only with people who need it for this mission, and delete exports when the mission is over. Follow your agency's policy on handling participant data.

The roster is saved in this browser on this device. It is not shared with other devices, and it is not sent anywhere.

Replace the roster

Import roster above replaces the whole roster from a JSON file and leaves your field reports and settings alone. Use it to bring a team's roster onto a device. The file can be one this app exported, a mission export, or any JSON list of rangers — each entry needs at least a callsign.

Export roster writes that file back out. Do it before importing if you want to keep the roster you already have.

Start from the built-in station list

Add station callsigns appends the 18 built-in Vashon station signs (command post, ACS, CERT and MERT teams) to whatever is already there. They are stations, not people. It adds rather than replaces, so pressing it twice gives you duplicates.

Empty the roster

Delete all rangers empties it and it stays empty — including after a reload. (Before v0.15.3 the built-in station list came straight back, which made loading your own roster a fight.)

Saving edits

Edits made directly in the grid are held in memory until you press Save edits. Importing, adding and deleting save themselves.


To move a whole mission — roster, settings and field reports together — use Export/Import Mission on the Settings page. To move only the roster, use Import/Export roster above.
