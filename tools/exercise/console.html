A scenario is a folder with scenario.json, msel.csv, places.csv and teams.csv (and an optional media folder). If the folder picker is not offered, choose the files together. The sample button works only when this page is served (node tools/exercise/serve.js). See PACKAGE.md.

Settings for this class

When

Start and stop are scenario times. Leave blank for the whole script. Thinning drops only background rows; injects, decision points, tests and casualty rows always stay.

Casualty realism

Softened turns fatalities into critical injuries. As recorded uses radio-protocol wording for the dead. No names or photos of remains, ever.

Teams the trainees play

Rows sent by a played team become cue cards telling the trainee what to send. Every other team is simulated: its traffic goes in the catch-up file or is read out by you.

Debrief check

Load the class’s exported Report Packet (the .txt file from the app). The console lines it up against the script: which injects were logged, how late, and whether the planted personal details turned up in the log.

Without a time pair only logged and missed are shown. The pair is filled in from the last catch-up file or Play press.

Stress injector

Made-up traffic as Report Packets, to test operators and the app at speed. For thousands of entries use the command line: node tools/exercise/stress.js --rate=2000 --hours=3 --out=<dir>. This form does the same, in the browser; several files may ask your browser’s permission to download more than one.
